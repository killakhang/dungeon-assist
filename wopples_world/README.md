# Wopples World

A browser-first cozy multiplayer RPG prototype for Wopples and a small friend group.

## v0.1
- Shared 24x16 pixel-art world
- Wopples-style goblin avatar
- Keyboard movement and collision
- Cottage, farm plot, pond, trees and one NPC
- Interaction dialogue
- WebSocket multiplayer
- Server-authoritative canonical player positions
- Designed for 4-5 friends

Run `world_server.py` and open `/world?name=YourName`.
